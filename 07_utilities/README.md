# Utilities Directory

This directory contains utility files, assets, and supporting materials for the London Historical LLM project.

## Contents

### Images
- `1834protest.png` - Historical protest image
- `searchfilter.jpg` - Search filter interface image
- `Untitled1.png` - Project diagram
- `Untitled2.png` - Project diagram

### Data Files
- `expanded_metadata_london.csv` - Expanded metadata for London sources
- `Copy of London Documents for Time Capsule LLM.txt` - Original project documents

### Usage
These files are used by various components of the system:
- Images are referenced in documentation
- CSV files contain metadata for data sources
- Text files contain project notes and references

### Organization
All utility files are kept in this directory to maintain a clean project structure while preserving important assets and reference materials.
