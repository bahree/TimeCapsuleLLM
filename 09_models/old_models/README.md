# Old Models Directory

This directory contains previous versions of the London Historical LLM models and training scripts.

## Contents

### london_1800_1850_v0/
- Early version of the London LLM model
- Contains training scripts, tokenizer files, and model configurations
- Historical reference for development progression

### london_1800_1875_v0.5/
- Version 0.5 of the London LLM model
- Includes model checkpoints and tokenizer files
- Shows evolution of the training approach

## Purpose
These old models are preserved for:
- Historical reference
- Comparison with current models
- Recovery of previous work if needed
- Development progression tracking

## Note
These are archived versions and should not be used for current training or inference. Use the current model training system in `04_training/` instead.
